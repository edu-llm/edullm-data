# edullm-datasets agent skill

The canonical copy of this skill is installed at
`<project>/.claude/skills/edullm-datasets/SKILL.md` so agents in the project pick it up
automatically. This copy ships with the package so it can be installed into other repos'
`.claude/skills/` directories:

    cp skill/SKILL.md <other-project>/.claude/skills/edullm-datasets/SKILL.md

Keep the two in sync; the project copy is authoritative.
